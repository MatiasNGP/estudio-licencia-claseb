# Kilómetro B

Cuestionario interactivo para practicar y prepararse para el examen teórico de conducción clase B en Chile. Está desarrollado en un único archivo HTML e incluye 280 preguntas con sus alternativas e imágenes, basadas en un cuestionario en PDF.

## Modos de estudio

- **Estudio libre:** recorre todas las preguntas a tu ritmo, sin límite de tiempo. Puedes navegar entre ellas y volver a intentar las que quieras repasar.
- **Simulacro:** responde 35 preguntas aleatorias en un máximo de 45 minutos. Tres preguntas tienen doble puntaje, con un máximo de 38 puntos y una meta de 33 para aprobar la práctica.

Ambos modos muestran la corrección inmediatamente. En las preguntas de selección múltiple, la respuesta se evalúa al marcar la cantidad indicada de alternativas. Si te equivocas, se muestran las opciones correctas.

## Cómo usarlo de manera local

1. Descarga o clona el repositorio.
2. Abre `index.html` en tu navegador.
3. Elige el modo de estudio y comienza a responder.

No requiere instalación, servidor ni conexión a internet para practicar. Las preguntas y las imágenes están incluidas en el archivo. El avance se conserva mientras la página permanezca abierta, pero se pierde al cerrarla o recargarla.

## Tecnologías

HTML, CSS y JavaScript, sin dependencias externas para su funcionamiento.

## Sobre el contenido

Este es un proyecto de práctica, no una aplicación oficial de CONASET. El PDF de origen es un banco histórico y algunas respuestas fueron corregidas o actualizadas; esos cambios están señalados en el cuestionario. El simulacro incluye corrección inmediata como ayuda para aprender.

Se recomienda complementar el estudio con el material vigente de [CONASET](https://mejoresconductores.conaset.cl/DudasFrecuentes/LicenciaClaseB/).
